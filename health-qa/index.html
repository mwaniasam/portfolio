Find the vetted answer. Don't invent one.

For each question, the system finds the closest questions that health professionals have already answered, then chooses the answer with a strategy picked for each language. 01 · Problem

Health answers in the language people ask in

Five languages, four countries, and very few NLP tools for most of them. The answers are judged against references written by health professionals.

The competition asked for answers to 2,618 health questions across eight language–country subsets. Each answer is scored against a reference: ROUGE-1 and ROUGE-L, which reward word overlap, count for 37% each, and an LLM judge of factual accuracy, completeness and language quality counts for 26%. Overlap scoring punishes paraphrase, and in health a fluent answer that is wrong is worse than no answer.

02 · System

Retrieve, then choose per language

The final pipeline treats the training answers as a library. A question is matched to similar questions that already have expert answers, and the answer is chosen from the best fifteen. No single strategy was best everywhere, so each subset uses the one that scored best on its own held-out data.

Input
Test questionOne of eight language–country subsets
Retrieve
AfriE5-Large-instructAfrican-language embedder, fine-tuned question to question with hard negatives
FAISS, top 15Cosine search within the same subset; a second fine-tune blended in per language
Choose
Per-language routingConsensus vote, reranker and stitcher, or generation
Output
One answerThe same text in all three scored columns
SubsetStrategyWhy
Akan, AmharicXLM-RoBERTa cross-encoder reranks the candidates, then an extractive stitcher joins the best sentencesSingle retrieved answers missed too much of the reference; verbatim sentences recover overlap without paraphrase
English, GhanaQwen2.5-7B, fine-tuned with LoRA, writes the answerThe one subset where generation clearly beat the best possible retrieved answer

04 · What failed

Reported in full

Most of the 44 experiments lost. The log keeps each one with its result and the reason it was dropped, so the final pipeline can be traced back to evidence.

0.24

Generation lost to my own baseline

mT5-base scored 0.2396, AfriTeVa V2 0.2971 and free-form Qwen-7B answers 0.3505, all below 0.4908 for simple retrieval. Paraphrased answers lose word overlap with the reference.

Retrieve expert-written answers; generate only where it measurably wins, for Ghanaian English.
−0.0014

A better ROUGE that lost overall

A later file raised Ghanaian English ROUGE on held-out data by 0.017, but the LLM judge column fell by 0.0063, and the leaderboard score dropped.

Rejected. The final file is the one that scored best on all three columns.
Leak

A bug in my own tuning

While re-tuning the stitcher, a held-out question could retrieve itself as its own best match, which inflated local scores.

Caught and fixed before submission; the final file was checked clean.
Forgetting

One retriever for all languages hurt the strong ones

Fine-tuning the retriever on every subset at once lifted the weak languages and degraded the strong ones.

Blend the base and fine-tuned retrievers per language, with weights chosen on held-out data.
+0.01 given up

A paid API that helped, removed

Refining answers with the Gemini API added about 0.01 to the public score, but the final solution had to use open-source models only. Gemini was used in early experiments and is not in the final pipeline.

The final pipeline is fully open-source, so anyone can rerun it.
05 · Engineering

A scoring fix worth more than a model

The organiser's scorer splits text into words with Unicode-aware rules. My first local scorer did not, so Amharic and Akan answers were being scored wrongly on my machine, and every tuning decision for them rested on that.

Reproducible

A Colab notebook rebuilds the final file end to end: load data and cached embeddings, load the four trained models from Drive, run the builder. A local ROUGE harness matches the organiser's scorer, and a simulator weights local results by the test mix.

Responsible

Answers come from a corpus written by health professionals, and the strongest languages get no free-form generation at all. ROUGE disadvantages morphologically rich languages such as Akan and Amharic, so their numbers are read with that in mind.

06 · Limits and next

What the score does not show

Known limitations

Most answers are retrieved, not written, so quality depends on the corpus holding a similar question. ROUGE rewards overlap with one reference and can undervalue a correct answer phrased differently, especially in Akan and Amharic. Scores come from automatic metrics and an LLM judge, not from clinicians.

Next

Three ideas are logged but not run: a larger Qwen3 embedding model as an extra retrieval leg, answer length as a reranker feature, and pseudo-labelling the reranker on test questions. Each is logged with the reasoning behind it.

In health, the safest answer is often one an expert already wrote.
